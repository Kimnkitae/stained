Stained: Psychological Horror Visual Novel
Stained — это атмосферный психологический хоррор, разработанный на движке Phaser.js. Проект исследует темы изоляции и внутреннего напряжения через интерактивное повествование в формате визуальной новеллы.

"Когда стены начинают говорить, лучше перестать слушать."

🎮 Об игре
Stained — это мой проект для демонстрации навыков разработки на JavaScript и работы с игровыми циклами в Phaser. Основная цель проекта — передать гнетущую атмосферу хоррора через минималистичный визуальный стиль и повествовательные механики.

Жанр: Психологический хоррор, Визуальная новелла.

Движок: Phaser.js.

Стиль: 2D, атмосферный минимализм.

🛠 Технологический стек
Проект реализован с использованием чистого JavaScript:

Phaser.js — основной игровой фреймворк.

HTML5/CSS3 — структура и стилизация интерфейса.

Git — контроль версий проекта.

🕹 Управление
Игра максимально сфокусирована на погружении в сюжет, поэтому управление упрощено до одного действия:

[Пробел] — Взаимодействие с объектами, продвижение диалога, подтверждение выбора.

🚀 Как запустить
Поскольку игра работает через стандартный index.html, её можно запустить локально без сложной настройки окружения:

Клонируй репозиторий:
git clone https://github.com/KimnKitae/stained.git

Перейди в папку проекта.

Открой файл index.html в любом современном браузере.

Примечание: Для корректной работы Phaser (загрузки ассетов) рекомендуется использовать расширение Live Server (в VS Code) или любой локальный HTTP-сервер.
